## Как спрятан номер Zalo
Цель — чтобы номер не собирали массовые спам-боты, которые ищут цифры в HTML. Это не шифрование: кто захочет, раскодирует. Бот с настоящим браузером, который нажмёт кнопку, тоже его увидит.

1. **Секрет.** Номер лежит только в `.env` (`ZALO_PHONE=84…`, в git не попадает), копия — в менеджере паролей. Сайт собирается локально, поэтому секрет в GitHub больше не нужен. После правки `.env` перезапустить dev. Формат `84` + номер без первого нуля; пробелы, `+` и ноль в начале `messengers.ts` уберёт сам. Без переменной подставляется заглушка `84000000000`.
2. **Сборка.** `npm run build` / `npm run deploy` берут `ZALO_PHONE` из `.env`. `src/components/Inquiry/messengers.ts` читает `import.meta.env.ZALO_PHONE` и кодирует через `encodePhone` (перевернуть + base64). Этот файл импортировать только в серверной части Astro: если он попадёт в клиентский `<script>`, номер может оказаться в JS.
3. **HTML.** В разметку уходит `<a href="https://zalo.me/" data-zalo="<код>">`, цифр номера в ней нет. Запасной текст — «Открыть Zalo» (`qr_modal.open` в `ui.ts`).
4. **Клик.** `initContacts()` из `src/utils/contacts.ts` (вызывается в `Layout.astro` на всех страницах) ждёт `pointerdown` или `click` на любой `a[data-zalo]` и сразу раскрывает все такие ссылки на странице: ставит настоящий `href`, а во вложенный `[data-zalo-text]` пишет `zalo.me/84…`. Событие ловится на погружении, поэтому ссылка готова до перехода и до открытия модалки. Без JS откроется просто zalo.me.
5. **QR.** `public/images/qr/zalo.svg` — обычный файл, номер внутри картинки есть. Это принято сознательно: массовые боты картинки не распознают.

**Для страницы контактов:**
- Взять `zaloCode` из `messengers.ts` в серверной части `contacts.astro` (или компонента `_legacy_ContactsSection`) и вывести ссылку с `data-zalo={zaloCode}`. Скрипт подхватит её сам, отдельный JS не нужен.
- В `.md` оставить только подписи (label), без номера и без `url`.
- До клика показывать «Открыть Zalo» / «Mở Zalo», а не номер. Если нужен сам номер — добавить внутрь `<span data-zalo-text>`: он появится после первого клика. Но этот же клик откроет Zalo, поэтому для «показать номер» нужна отдельная кнопка (`button`, а не ссылка) — её `contacts.ts` пока не умеет.
- На десктопе `zalo.me/84…` без входа в Zalo показывает страницу логина. Лучше открывать ту же QR-модалку: вывести на странице `InquiryModals` и дать ссылке `data-hystmodal="#qr-modal-zalo"` — на мобильном она и так перейдёт по `href`.
- Проверить, что номера нет в исходном HTML (Cmd+Option+U), а не в DevTools: там после клика он уже виден.

Что пробовали и не подошло: личный QR из Zalo (`zaloapp.com/qr/p/…`) не содержит номера, но работает только через сканер внутри Zalo — камера и Chrome уводят на лендинг, на компьютере открывается главная Zalo. Zalo OA (бизнес-аккаунт) скрыл бы номер совсем, но для подтверждения нужна регистрация бизнеса (hộ kinh doanh или компания).


**Идеи**
Калькулятор размера: спросить или выяснить у пользователя устрйоства (или может пользователь сам выбирает, чтобы не сталкиваться с персональными данными и куками). Далее узнаём PPI (или может из JS как-то узнаем), и показываем ему масштабированное фото уменьшив или увеличив по сантиметрам.
